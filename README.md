# 🌀 Projek Instal Ulang OS (Jalur Ghaib & Pasrah)

Selamat datang di repositori **Instal Ulang OS** paling tidak ramah mental, tapi dijamin menghibur. Script ini dibuat khusus untuk kamu yang laptopnya udah mulai batuk-batuk, lemot gara-gara kebanyakan nyimpen file "Tugas_Final_v2_fix_banget_bismillah.docx", atau sekadar gabut pengen ngerasain sensasi jadi hacker siber (padahal cuma pencet enter).

## 🚀 Fitur Utama (Klaim Sepihak)
- **Deteksi Dosa Sistem**: Menghapus cache, penyesalan masa lalu, dan file mantan yang menumpuk.
- **AI-Powered Pasrah**: Algoritma otomatis yang ikut pasrah kalau instalasinya gagal.
- **Anti-Gagal (Bohong)**: Persentase keberhasilan tergantung amal dan ibadah user.

## 🛠️ Cara Menjalankan
Buka terminal kamu, lalu ketik mantra berikut (khusus pengguna Linux/macOS, atau Git Bash di Windows):

```bash
chmod +x install_os.sh
./install_os.sh
```
