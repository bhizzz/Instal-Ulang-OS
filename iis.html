Windows Post-Install & IIS Guide

Portal unduhan tools instal ulang dan panduan pembuatan Web Server IIS lokal

Cara Membuat Web Server IIS di Laptop Anda:

  1. Tekan tombol Windows + R di keyboard, ketik optionalfeatures, lalu tekan Enter.
  2. Cari pilihan Internet Information Services (IIS), lalu beri centang pada kotak tersebut dan klik OK.
  3. Setelah terpasang, file website ini bisa Anda pindahkan ke folder bawaan IIS komputer Anda di direktori: C:\inetpub\wwwroot\
  4. Buka browser baru, ketik localhost di kolom alamat untuk menguji server lokal Anda sendiri.
