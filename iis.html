Panduan Lengkap Membangun Web Server IIS

Dokumentasi Admin Jaringan Lokal untuk Server Download Installer Windows

1. Mengaktifkan Fitur IIS di Windows

IIS adalah fitur bawaan Windows yang berfungsi mengubah laptop Anda menjadi server, tetapi statusnya harus diaktifkan manual:


  1. Tekan tombol Windows + R di keyboard untuk membuka menu Run.
  2. Ketik optionalfeatures lalu tekan Enter. Halaman "Windows Features" akan terbuka.
  3. Cari pilihan Internet Information Services, kemudian beri tanda centang pada kotak utamanya.
  4. Klik tombol OK. Windows akan mengunduh berkas yang diperlukan. Jika diminta melakukan restart komputer, silakan restart terlebih dahulu.

2. Menyiapkan Folder Website & Berkas Installer

Setelah IIS aktif, Windows akan menyediakan folder khusus server di komputer lokal Anda:


  1. Buka File Explorer, masuk ke folder sistem server Anda di direktori: C:\inetpub\wwwroot\
  2. Simpan berkas index.html (halaman utama portal) ke dalam folder tersebut.
  3. Buat folder baru di dalam direktori tersebut dengan nama tools, sehingga jalurnya menjadi: C:\inetpub\wwwroot\tools\
  4. Masukkan berkas mentah aplikasi installer (seperti Driverpack, Chrome, WinRAR) ke dalam folder tools tersebut.

3. Konfigurasi MIME Types (Mengatasi Error Gagal Download)

Secara bawaan, IIS akan memblokir proses unduhan file berformat .exe atau .zip karena dianggap membahayakan. Anda harus memberikan izin khusus:


  1. Buka Start Menu, cari dan buka aplikasi Internet Information Services (IIS) Manager.
  2. Pada panel sebelah kiri, klik nama komputer Anda, lalu klik folder Sites dan pilih Default Web Site.
  3. Di panel bagian tengah, klik dua kali pada ikon bernama MIME Types.
  4. Lihat ke panel sebelah kanan, klik menu Add...
  5. Masukkan data berikut:
    - File name extension: .exe
    - MIME type: application/octet-stream
  6. Klik OK. Lakukan hal yang sama untuk ekstensi .zip atau .rar jika Anda menyimpannya dalam bentuk arsip.

4. Membuka Windows Firewall (Izin Koneksi Perangkat Lain)

Agar laptop pasien atau komputer lain di jaringan Wi-Fi yang sama bisa mengakses server download Anda, Windows Firewall harus diberi celah masuk:


  1. Buka Start Menu, cari dan buka Windows Defender Firewall with Advanced Security.
  2. Di panel sebelah kiri, pilih menu Inbound Rules.
  3. Di panel sebelah kanan, klik menu New Rule...
  4. Pilih opsi Port lalu klik Next. Pilih TCP dan pada bagian *Specific local ports* isi dengan angka: 80
  5. Klik Next, pilih Allow the connection, lalu klik Next terus sampai halaman akhir.
  6. Beri nama rule baru tersebut bebas (misalnya: Web Server IIS Lokal), lalu klik Finish.

5. Cara Menghubungkan Laptop Lain ke Server

Setelah konfigurasi selesai, server Anda siap digunakan lintas perangkat tanpa kuota internet:


  1. Buka Command Prompt (CMD) di laptop server Anda, ketik ipconfig lalu tekan Enter.
  2. Cari baris bernama IPv4 Address (Contoh: 192.168.1.15).
  3. Pastikan laptop server dan laptop lain sudah terhubung ke satu Wi-Fi/Hotspot yang sama.
  4. Buka browser di laptop lain tersebut, ketik IP Address Anda di kolom pencarian alamat (contoh: http://192.168.1.15) lalu tekan Enter.
  5. Halaman portal download akan terbuka, dan mereka bisa mengunduh Driverpack langsung dari server lokal Anda dengan kecepatan penuh!
Catatan Penting: Pastikan status Wi-Fi Anda diatur ke mode Private Network di pengaturan Windows agar sistem deteksi perangkat lokal dapat berjalan lancar.
