Panduan Instal Ulang Windows

Petunjuk Lengkap Langkah Demi Langkah untuk Pemula

Tahap 1: Persiapan Sebelum Instalasi
Langkah 01

Backup Data Penting

Pindahkan semua file penting dari Drive C (termasuk folder Desktop, Documents, dan Downloads) ke Drive D atau Hardisk Eksternal agar tidak terhapus.

PENTING: Proses instal ulang akan menghapus seluruh data di partisi sistem (Drive C).
Langkah 02

Siapkan Bootable Flashdisk

Gunakan aplikasi seperti Rufus dan file ISO Windows resmi untuk membuat Bootable Flashdisk minimal berukuran 8 GB.

Tahap 2: Proses Instalasi Utama
Langkah 03

Masuk ke Menu BIOS/Boot Menu

Colokkan Flashdisk, nyalakan laptop, lalu tekan tombol BIOS (biasanya F2, F12, atau DEL tergantung merk laptop) untuk mengatur agar komputer booting pertama kali dari Flashdisk.

Langkah 04

Mulai Windows Setup & Format Partisi

Pilih bahasa dan format waktu, klik Install Now. Pilih opsi Custom: Install Windows only (advanced). Format partisi Drive C lama Anda, lalu pilih partisi tersebut sebagai lokasi instalasi baru.

Langkah 05

Proses Copy Files

Tunggu proses instalasi berjalan hingga 100%. Laptop Anda akan otomatis melakukan restart beberapa kali selama proses ini berlangsung.

Tahap 3: Finishing & Setup Awal
Langkah 06

Konfigurasi Windows

Ikuti panduan di layar seperti memilih Wilayah (Region), Layout Keyboard, membuat Akun Pengguna, dan mengatur opsi privasi Windows Anda.
